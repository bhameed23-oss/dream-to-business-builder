# Website Skeleton

This is a starter structure for a website or portal that can eventually be hosted at dream.belvi.casa.

## Planned structure

```text
website/
├── index.html
├── styles.css
├── script.js
├── assets/
├── pages/
│   ├── home/
│   ├── about/
│   ├── framework/
│   ├── demo/
│   ├── contributors/
│   └── contact/
└── README.md
```

## Notes

The website should be plain, modern, accessible, and friendly to non-technical users.

It should explain:
- what the framework is
- who it helps
- how it works
- why security and compliance matter
- how to get started
- how to contribute
