# Beginner Mode and Expert Mode

This project supports two essential paths.

## Beginner mode

Beginner mode is a calm, step-by-step flow that:

- asks simple questions
- uses plain language
- avoids jargon whenever possible
- explains tradeoffs clearly
- asks for approval before major moves
- helps users build confidence gradually

### Beginner mode principles

- one step at a time
- low overwhelm
- no unnecessary technical detail
- no pressure to launch immediately
- no shame for being inexperienced

## Expert mode

Expert mode is designed for people who want a more advanced system and a deeper operational review.

Expert mode can include:

- more detail on process design
- more advanced automation logic
- industry-specific data handling and risk checks
- deeper business modeling
- stronger review of tools and integrations
- operational maturity and growth planning

### Expert mode principles

- do not ignore security or compliance
- still keep high clarity
- still ask for approvals before major action
- structure review and execution clearly

## The same core system, different experience levels

The framework should feel like one system, with multiple user experiences:

- a beginner who needs guidance
- an operator who needs structure
- an expert who wants a deeper view
- a professional who wants to review the work

## Example wording for beginner mode

> We are going to build this slowly and carefully. We will ask the next question, review the answer, and decide what is most important before we build anything.

## Example wording for expert mode

> We will map the business, assess the workflow, identify risk, and choose the best operational path before we implement automation.
