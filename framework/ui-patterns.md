# UI Pattern Ideas for the Lifecycle Product

This file outlines how the lifecycle could be presented in a product UI.

## Recommended screens

### Landing page
- headline and value proposition
- path selection
- simple explanation of the lifecycle
- trust and safety message

### Intake screen
- choose the business situation
- answer 5 to 10 high-value questions
- decide the starting phase

### Dashboard screen
- current phase
- business health score
- top priorities
- next steps
- risks and review triggers
- tool and integration overview

### Phase detail screen
- phase summary
- action list
- risk review checklist
- approval checkpoint
- summary export

### Business profile screen
- company overview
- customer profile
- operations summary
- automation overview
- compliance overview
- exit readiness overview

### Integration screen
- connected tools
- active workflows
- automation paths
- AI helper overview
- review and security status

## UX principles

- low cognitive load
- clear progress feedback
- simple language
- confidence-building tone
- visible safety warnings
- suggestion of human review when necessary

## Why it matters

The product experience should feel like a calm guide rather than a confusing checklist generator.
