# Productized Lifecycle Experience

This file defines how the lifecycle framework can be presented as a product experience instead of a collection of docs.

## Product goals

- help the user identify their current phase quickly
- guide them through the next best step without overwhelming them
- maintain a shared business profile across the whole journey
- present risk, progress, and actions clearly
- offer a path for both beginners and experienced operators
- keep safety and human-review steps visible

## Core user experience

### 1. Start here
The user chooses a starting point:
- new business
- existing business
- improve operations
- scale faster
- catch up on compliance
- automate and improve workflows
- prepare for exit or sale

### 2. Guided intake
The system asks a small number of high-value questions:
- what is the business?
- what is the current pain point?
- what is the current goal?
- where is the risk?
- what is the next desired outcome?

### 3. Lifecycle dashboard
The user receives a dashboard showing:
- current phase
- key risk summary
- growth or operations summary
- recommended next actions
- business health score
- tool and automation overview

### 4. Phase action flow
The user enters a phase and receives:
- short overview
- review questions
- action items
- risk check
- approval checkpoint
- output summary

### 5. Business profile continuity
Every phase updates the same shared business profile, so the user isn’t starting from zero every time.

## Product promise

This product helps people move from confusion to structure without forcing them to know all the technical, legal, or operational language in advance.
