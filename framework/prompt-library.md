# Lifecycle Prompt Library

This file stores the prompt structure for the system and can be used by AI or guided flows.

## Prompt categories
- lifecycle identification
- business profile creation
- audit prompts
- scaling prompts
- compliance prompts
- automation prompts
- exit prompts

## Example prompt structure
```text
You are helping a user assess their business at a certain lifecycle stage.

Goal: identify the current phase, review the business health, highlight the biggest issues, and recommend the best next actions.

Please provide:
1. current phase
2. current risk summary
3. the biggest bottlenecks
4. recommended next steps
5. whether professional review is needed
6. a clear summary for the user
```

## Why it matters

The prompt library keeps the lifecycle guidance consistent and replicable across product flows and AI-assisted experiences.
