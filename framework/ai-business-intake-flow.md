# AI Business Intake Flow

This file is a starter decision path for guiding new users through the system.

## Primary steps

1. Discover the business and idea
2. Understand the customer and offer
3. Review the existing business process
4. Identify current pain points
5. Identify data and compliance risk
6. Choose a likely path
7. Present 3 options
8. Recommend a path
9. Gather approval
10. Create a plan and milestone roadmap
11. Build in stages
12. Review and improve

## Example intake logic

### If user says they have a business idea
- Start with discovery questions
- identify market and offer
- then assess risk and complexity

### If user says they have an existing business
- run the business system check
- identify what is manual and bottlenecked
- propose automation and operational improvements

### If user says they need a website only
- review brand and trust needs
- then add contact, booking, and lead handling
- require security and privacy review if personal data is collected

### If user says they need a full business system
- build a structured phase plan from discovery through launch
- require compliance and launch readiness review before live deployment

## Core principle

The goal is to guide people toward the simplest useful version first, then allow growth over time.
