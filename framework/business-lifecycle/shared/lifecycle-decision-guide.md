# Lifecycle Decision Guide

This guide helps decide which phase is the best starting point for the user.

## Decision rules

- If the user is starting from zero: Creation
- If they already have a business but no structure: Operation or Auditing
- If they are overwhelmed by growth: Scaling
- If they have missed privacy or compliance basics: Compliance Catch-Up
- If they have repeated manual work: Automation & Systems Upgrade
- If they want to sell or transfer: Exit Readiness

## Why this matters

The framework should direct people to the phase that best matches their real situation instead of assuming they all need the same answer.
