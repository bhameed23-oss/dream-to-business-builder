# Automation & Systems Upgrade Phase

This phase is about modernizing the business system with the right automation and tool improvements.

## Purpose

The automation phase answers:

- What work is repetitive, repetitive, or easy to standardize?
- What could be automated safely?
- What needs a human in the loop?
- What systems should be upgraded before scaling?

## Core principles

- simplify before automation
- review the data flow
- keep permissions limited
- use human approval where risk is present
- make the system easier to understand and maintain

## Examples of good automation candidates

- appointment reminders
- lead follow-up
- intake form handling
- internal status alerts
- recurring reporting
- repeatable customer communication

## Output

- automation opportunity list
- system improvement plan
- human-review list
- implementation order
- risk and security review for new integrations
