# Automation & Systems Upgrade Resources

## No-code automation tools (good starting points)

- **Zapier** — Connects apps you already use (email, calendar, CRM, forms) without writing code. Free tier available for simple automations.
- **Google Forms + Google Sheets** — Free way to automate intake and data collection before investing in anything more complex.
- **Calendly** (or similar) — Free/low-cost tier for automating appointment scheduling and reminders.

## Learning the basics

- **[SBA - Technology guidance](https://www.sba.gov/business-guide/manage-your-business)** — General federal guidance on using technology to run a small business.

## Security when automating

- **[FTC - Cybersecurity for Small Business](https://www.ftc.gov/business-guidance/small-businesses/cybersecurity)** — Read this before connecting new tools to customer data — every new integration is a new place data can leak.

## When to bring in a professional

Talk to a developer or automation consultant if:
- The automation needs to touch payment or sensitive customer data
- You've outgrown no-code tools and need something custom-built
- You're not confident you understand what a tool does with the data once it's connected
