# Automation & Systems Upgrade Checklist

Use this after reading README.md in this folder. Rule of thumb: **simplify the process first, automate it second.** Automating a messy process just makes mistakes happen faster.

## 1. Find real automation candidates

- [ ] List every task you or your team does that is repetitive and follows the exact same steps each time.
- [ ] For each one, ask: "Could a computer do this exactly the same way every time?" If yes, it's a good candidate.

## 2. Rule out bad candidates

- [ ] Cross off anything that requires judgment, empathy, or a case-by-case decision — these need a human, at least for now.
- [ ] Cross off anything you haven't done consistently the same way at least 10 times yourself. If you don't have a stable process yet, there's nothing reliable to automate.

## 3. Check the data flow

- [ ] For each remaining candidate, write down: what information goes in, and where does it go after?
- [ ] Flag anything that involves customer personal data — these need extra care and possibly a compliance review first.

## 4. Decide what needs a human in the loop

- [ ] For each automation candidate, decide: fully automatic, or does a human need to approve it before it happens? (Sending a payment reminder = probably fine automatic. Sending a legal notice = needs human approval.)

## 5. Set your rollout order

- [ ] Rank your automation list by: highest time savings + lowest risk first.
- [ ] Pick ONE to implement first. Don't automate five things at once — you won't be able to tell what broke if something goes wrong.

## Done when

You have a short list of real automation candidates (not everything repetitive — just the safe, stable ones), you know which need human approval, and you know which one you're doing first.
