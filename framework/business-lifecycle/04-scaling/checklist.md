# Scaling Phase Checklist

Use this after reading README.md in this folder. This phase is about growing without breaking what already works.

## 1. Find your growth stress points

- [ ] Think back to your busiest week recently. What broke down, slowed down, or got skipped?
- [ ] List the tasks that only work because you personally are watching them closely.

## 2. Test if it can handle more

- [ ] For your core process, ask: "If I got 3x the customers tomorrow, what would break first?"
- [ ] Write down the answer honestly — this is your #1 scale blocker.

## 3. Decide what needs a system before it needs volume

- [ ] List what should be standardized (written down so it's done the same way every time) before you grow.
- [ ] List what should be delegated (handed to someone else) before you grow.
- [ ] List what should be automated (handled by a tool) before you grow.

## 4. Check ownership and roles

- [ ] If you have any help (employees, contractors, family), write down who owns which part of the business. If the answer is "everyone does everything," that's a scale risk.
- [ ] Identify one decision you currently make that someone else could make instead, with the right guidelines.

## 5. Revisit risk at the new scale

- [ ] More customers usually means more data, more money moving, and more exposure. Note anything from the Compliance phase that becomes more urgent as you grow.

## Done when

You know exactly what breaks first if volume increases, you've listed what needs to be standardized or delegated before growing, and you understand who owns what.
