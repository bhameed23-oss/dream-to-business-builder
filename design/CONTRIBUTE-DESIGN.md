# Design Contribution Guide

This file is for designers who want to improve the framework and help more businesses build a strong, welcoming, high-trust experience.

## What to contribute

- brand system templates
- landing page direction
- accessibility upgrades
- customer journey flows
- design principles for small businesses
- trust-building UI patterns
- mobile-first design examples

## Recommended approach

- design for trust, not just style
- keep clarity high
- avoid complexity for the sake of complexity
- use accessibility and plain language as part of the design system

## Community goal

The goal is to help more people present themselves professionally without needing a huge budget.
