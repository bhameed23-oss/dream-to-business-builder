# CLI Connection Overview

This guide helps explain how a user can connect command-line tools, scripts, and local business utilities to the broader framework.

## Typical examples

- CLI tools for file processing
- local automation scripts
- command-line business utilities
- custom scripts for reporting, alerts, or data processing
- developer tools used by the business or a consultant

## Design goal

The system should help users understand how CLI tools can fit into their business without requiring deep technical experience. The system should avoid jargon and present the practical purpose of the tool first.

## Important rule

Do not grant broad permissions or sensitive data access from a CLI tool without review. Least privilege matters.
