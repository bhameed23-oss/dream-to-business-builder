# Screen-by-Screen Product Flow

This file provides the exact screen flow for the MVP.

## Screen 1: Starting situation
- user chooses a general business situation
- user picks a starting goal

## Screen 2: Intake form
- asks the onboarding questions
- allows users to save progress

## Screen 3: Business profile summary
- summary of business concept
- customer summary
- tools in use
- main risk areas
- current phase recommendation

## Screen 4: Dashboard
- lifecycle phase
- business health score
- risk summary
- next actions
- tool overview
- suggested outputs

## Screen 5: Phase detail
- summary of the current phase
- prioritized actions
- what to delay
- review triggers
- next best move

## Screen 6: Save and revisit
- user can return later and update their business profile
- data remains connected and current
