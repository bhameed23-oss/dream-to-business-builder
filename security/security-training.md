# Security Training

This module is meant to help non-technical users understand the basics of security without being overwhelmed.

## Core topics

- how to create strong passwords
- why 2FA matters
- how phishing works
- how to protect customer data
- when to use encryption and when not to trust a system
- why backups matter
- how to safely use third-party tools and APIs
- how to recognize suspicious access or requests
- why regular updates matter

## Plain-language approach

The framework should explain security in simple terms:

> Security is not about being perfect. It is about making a system harder to attack and easier to recover from mistakes.

## Starting guidance

- Use unique passwords for each account
- Turn on MFA wherever possible
- Store only the data you actually need
- Review third-party tools before handing them customer data
- Back up critical information regularly
- Keep software updated
- Review access permissions regularly
- Learn how to spot phishing and scam messaging

## Important warning

Security is a business process, not just a technical issue. If you are handling sensitive or regulated information, you should involve a professional reviewer.
